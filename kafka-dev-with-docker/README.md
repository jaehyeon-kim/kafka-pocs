- `bitnami/kafka:2.8.1` → `bitnamilegacy/kafka:2.8.1`
- `bitnami/zookeeper:3.5` → `bitnamilegacy/zookeeper:3.5`
- `bitnami/python:3.9` → `bitnamilegacy/python:3.9`
